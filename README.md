# AI-Chatbot
# 🤖 AI Chatbot Using NLP and Transformers

## 📌 Overview

The **AI Chatbot** is a simple conversational application developed using **Python, Natural Language Processing (NLP), Transformers, and Gradio**. It allows users to communicate with an AI model through a simple web-based chat interface.

The chatbot uses the **DialoGPT-small** conversational model from Hugging Face Transformers to generate responses based on user messages.

## 🎯 Objectives

* To develop a simple AI-powered chatbot.
* To understand the basics of Natural Language Processing.
* To use a pre-trained conversational Transformer model.
* To create an interactive chatbot interface using Gradio.
* To run the complete application easily in Google Colab.

## 🛠️ Technologies Used

* **Python**
* **Natural Language Processing (NLP)**
* **Hugging Face Transformers**
* **DialoGPT-small**
* **PyTorch**
* **Gradio**
* **Google Colab**

## ⚙️ How It Works

1. The user enters a message in the chatbot interface.
2. The message is passed to the conversational AI model.
3. The model analyzes the conversation history.
4. DialoGPT generates a suitable response.
5. The generated response is displayed in the chatbot interface.

## ✨ Features

* 💬 Interactive chat interface
* 🤖 AI-generated responses
* 🧠 NLP-based conversation
* 🔄 Conversation history support
* 🌐 Gradio web interface
* ☁️ Runs directly in Google Colab
* 🚀 Easy to use and beginner-friendly

## ▶️ How to Run

### Step 1: Open Google Colab

Create a new notebook in Google Colab.

### Step 2: Add the Chatbot Code

Copy the complete chatbot code into a single Colab cell.

### Step 3: Run the Cell

Click the **Run ▶** button.

### Step 4: Open the Application

After the required models and libraries are loaded, Gradio will provide a link to open the chatbot.
